# Как запустить полный проект

В этом архиве находится весь проект FORMA на Vue 3 + Tailwind CSS 4 с последними исправлениями зависимых фильтров. Все исходники, компоненты, настройки, каталог, изображения, шрифты, тесты и готовая сборка включены.

## 1. Распакуйте архив

После распаковки появится папка `kitchen-set`. Не запускайте команды внутри ZIP. Откройте терминал в распакованной папке, в которой находится `package.json`.

## 2. Подготовьте Node.js

Используйте Node.js 22.12 или новее с npm. Проверка установки:

```bash
node -v
npm -v
```

## 3. Установите зависимости и запустите страницу

Если терминал открыт в родительской папке:

```bash
cd kitchen-set
npm ci
npm run dev
```

Если вы уже находитесь в папке с `package.json`, пропустите `cd kitchen-set`.

После `npm ci` автоматически создаётся папка `node_modules`. Для первой установки нужен доступ к интернету и публичному реестру npm. Вручную создавать файлы или добавлять компоненты не требуется.

Откройте http://localhost:5173 в браузере. Если порт занят, используйте адрес из терминала. Сервер продолжает работать, пока открыт процесс в терминале. Остановка — Ctrl+C.

## 4. Проверки и сборка

```bash
npm test
npm run build
npm run preview
```

Проверки охватывают подбор, скидки, зависимость параметров, недоступные теги, смену цвета, дополнительные характеристики и восстановление по ссылке. Сборка записывается в `dist`. Предпросмотр обычно доступен на http://localhost:4173 — точный адрес напечатает терминал.

Готовая папка `dist` уже приложена. Её можно разместить на обычном статическом веб-сервере, обслуживая содержимое `dist` от корня домена. Если исходники изменены, выполните `npm run build` перед размещением.

Не открывайте `index.html` двойным щелчком: страница загружает JSON и модули через HTTP, поэтому нужен сервер разработки, предпросмотра или статический хостинг.

## Где что менять

- `src/App.vue` — основная страница и обработчики действий.
- `src/style.css` — стили и адаптивная вёрстка.
- `src/engine.js` — подбор, зависимые параметры, скидки и восстановление состояния.
- `src/components/FilterFields.vue` — кнопки и чекбоксы с проверкой доступности.
- `src/components/ProductCard.vue` — карточка товара.
- `src/components/BaseModal.vue` — всплывающие окна.
- `src/components/AppIcon.vue` — иконки.
- `public/data/config.json` — меню, группы, характеристики, скидки и настройки подключения магазина.
- `public/data/products.json` — тестовый каталог из 621 товара.
- `public/images` — все фотографии товаров.
- `public/fonts` — локальные шрифты и лицензия.
- `README.md` — подробная документация и контракт подключения магазина.
- `FILES.txt` — полный список файлов архива.
- `SHA256SUMS.txt` — контрольные суммы файлов.

Каталог и корзина демонстрационные. Для реальных заказов подключите каталог и API магазина по инструкции в README.md. Источники и сведения о правах на фотографии приложены в `public/data/image-sources.json`.
