# FORMA — конфигуратор комплекта кухонной техники

Адаптивная посадочная страница на Vue 3 (Composition API, SFC), Tailwind CSS 4 и Vite. Тестовый каталог содержит 621 вымышленный товар. Бренд FORMA, модели и цены используются для демонстрации.

## Запуск

```sh
npm ci
npm run dev
```

`npm run build` создаёт статическую сборку в `dist`. `npm test` проверяет фильтрацию, границы скидок, выбор бюджета, сохранение комплекта в ссылке и полноту каталога.

## Настройка меню

`public/data/config.json` загружается при открытии страницы. Для изменения настроек после публикации замените соответствующий JSON и опубликуйте обновление.

- `sections` — порядок разделов, заголовки, иконки, тип отображения и колонка (`configuration` или `result`). Поддерживаются `color-select`, `appliance-accordion`, `budget-select`, `product-results`, `price-summary`, `checkout-actions`.
- `steps` — порядок и подписи шкалы прогресса; `target` соответствует `id` раздела.
- `groups` — порядок категорий и результата, названия, иконки, параметры по умолчанию и список полей.
- `fields[].type` — `single`, `multi` или `toggle`. `advanced: true` оставляет поле только в окне «Уточнить». `required: true` запрещает снять обязательное значение. `exclusive` задаёт взаимно исключающие значения внутри мультивыбора.
- `colorApplies` — влияет ли цвет на категорию. Встроенные приборы за фасадом исключены из цветового фильтра. Отдельно стоящие посудомоечные машины проверяют цвет.
- `discounts` — проценты по минимальному количеству разных групп.
- `initialState` — начальный цвет, бюджет и состав.

Пример группы:

```json
{
  "id": "oven",
  "title": "Духовой шкаф",
  "icon": "Microwave",
  "colorApplies": true,
  "defaults": { "width": 60 },
  "fields": [
    { "id": "width", "label": "Ширина, см", "type": "single", "options": [40, 60], "unit": "см" },
    { "id": "convection", "label": "Конвекция", "type": "toggle", "advanced": true }
  ]
}
```

Опечатка «Rjhpbyf» из задания интерпретирована как «Корзины»: представлены две или три корзины, отдельно — автооткрытие.

## Данные товаров

`public/data/products.json` — объект с массивом `products`. Страница фильтрует только этот каталог. Пример структуры:

```json
{
  "id": "oven-0003",
  "groupId": "oven",
  "name": "Linea O602B",
  "series": "FORMA / LINEA",
  "description": "Электрический · 72 л",
  "price": 42990,
  "currency": "RUB",
  "color": "black",
  "available": true,
  "image": "/images/oven.webp",
  "url": "/?product=oven-0003",
  "attributes": { "width": 60, "features": ["airfry", "catalytic"], "convection": true, "volume": 72 }
}
```

В рабочем каталоге замените модели, фотографии, цены, характеристики и `url` реальными данными магазина. Демонстрационные фотографии иллюстрируют категории и не гарантируют совпадение цвета, установки и параметров вымышленных моделей. Источники фотографий и сведения о правах находятся в `public/data/image-sources.json`. Фотографии принадлежат Gorenje; открытая лицензия не установлена. Для коммерческого использования используйте разрешённые магазином изображения. Manrope распространяется по SIL Open Font License, файл `public/fonts/OFL.txt`.

`scripts/generate-demo-catalog.mjs` воспроизводит демонстрационный JSON. Он не запускается при загрузке страницы и не нужен после подключения рабочего каталога.

## Подбор и скидки

Активные условия объединяются по И. Все выбранные теги должны присутствовать у товара. Нажатие на активное необязательное значение снимает фильтр. Пиролитическая и каталитическая очистка взаимоисключающие.

Параметры зависимы: доступность каждой кнопки и чекбокса вычисляется по точному состоянию после предполагаемого нажатия с учётом цвета, всех остальных условий и дополнительных полей из «Уточнить». Вариант без совпадений получает нативный `disabled`, серый фон и текст, пунктирную границу и пояснение. Он не реагирует на мышь и клавиатуру. Выбранный необязательный параметр можно снять, чтобы снова открыть несовместимые с ним варианты.

И основная форма, и окно «Уточнить» проверяют изменения до записи в состояние. Начальные параметры, смена цвета и старые ссылки проходят сверку с реальным наличием в каталоге. Обязательные поля сохраняют допустимые значения; остальные требования сохраняются в порядке JSON, пока для них есть хотя бы один товар. Несовместимые условия снимаются автоматически. Если в группе совсем нет товаров выбранного цвета, добавить её нельзя; цвет, полностью исключающий одну из уже выбранных групп, также недоступен. Группы, полностью исчезнувшие из каталога, исключаются при восстановлении старой ссылки.

Бюджет выбирает минимальную, медианную или максимальную цену среди совпадений. «Дешевле» и «Дороже» переключают на ближайшую строго меньшую или большую цену. При изменении условий и бюджета ручной выбор пересчитывается. «Уточнить» редактирует копию параметров; отмена и Escape сохраняют исходные настройки.

Для одной группы скидка 0%, двух — 5%, трёх — 8%, четырёх и более — 10%. Расчёт производится в копейках. Форма сохраняет только сочетания с подходящими товарами, поэтому сценарий «недооформленный выбор в группе» не возникает. Проверка полноты комплекта перед добавлением в корзину остаётся внутренней защитой.

## Подключение магазина

В `config.json`:

```json
{
  "integrations": {
    "cartEndpoint": null,
    "cartUrl": null,
    "productUrlTemplate": null
  }
}
```

- `productUrlTemplate`: необязательный шаблон вроде `/catalog/{id}`. При `null` используется `product.url`. В демо ссылка открывает локальную карточку товара с полным списком характеристик.
- `cartEndpoint`: при указании адреса выполняется POST с `Content-Type: application/json` и телом `{ "source": "kit-builder", "items": [{ "productId": "...", "quantity": 1 }] }`. Успех — ответ 2xx. При другом контракте отредактируйте `addToCart` в `src/App.vue`. Публичный HTML/JSON не должен содержать секреты.
- `cartUrl`: адрес корзины магазина, открываемый кнопкой корзины. При `null` показывается демонстрационная корзина.

При незаданном endpoint используется демо-корзина в localStorage текущего браузера. Добавление повторно не дублирует категорию: последняя модель заменяет предыдущую. При удалении товара скидка пересчитывается. Реальные наличие, цены, скидки и окончательную сумму должен подтверждать сервер магазина. В демо оформление заказа не производится.

Кнопка «Поделиться» создаёт ссылку с цветом, составом, бюджетом, всеми уточнениями и идентификаторами товаров. Получатель восстанавливает тот же выбор, цены берутся из каталога на момент открытия. Доступ к самой странице зависит от настроек её публикации.

## Компоненты

- `src/components/ProductCard.vue` — переиспользуемый шаблон карточки товара.
- `src/components/FilterFields.vue` — поля, формируемые из JSON.
- `src/components/BaseModal.vue` — нативный dialog с Escape, возвратом фокуса и прокруткой.
- `src/engine.js` — фильтрация, бюджеты, скидки и формат состояния ссылки.

Палитра карточек: фон `#F2E8DE`, обводка `#B69472`, заголовки `#1E1A17`, описания `#5F5147`, иконки `#8A6542`.

Вёрстка переключается на одну колонку при ширине до 940px; на телефонах доступна нижняя панель с итогом. Интерфейс поддерживает управление клавиатурой, состояния отсутствия результатов и ошибки загрузки, уменьшенную анимацию. Проведены проверка production-сборки и тесты логики; браузерное визуальное тестирование не проводилось.
